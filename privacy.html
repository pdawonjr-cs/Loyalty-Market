What this preview does

LocalMarket Liberia is an early marketplace preview. Product listings are sample content. When you use checkout or submit a vendor application, the information you provide is sent to the LocalMarket server and stored in its SQLite database so marketplace administrators can review and manage the request. The preview does not process payments, arrange deliveries, or send order notifications to vendors.

Information processed

Order requests include your name, phone number, delivery area, payment preference, selected products and quantities, and the order total. Vendor applications include the business name, contact name, phone number, category, community, and business description. Marketplace administrators can view these records to review applications and manage orders. The server also temporarily uses the source IP address to limit repeated failed administrator sign-in attempts; it does not intentionally write IP addresses to the application database.

Administrator account and session

The administrator password is processed by the server and stored as a salted scrypt hash. The original password is not stored. A successful sign-in creates a random, server-managed session represented by an HttpOnly cookie. The session expires after four hours or when the administrator signs out. The cookie uses Secure when LocalMarket is served from an HTTPS origin and SameSite=Strict in all cases.

Storage, sharing, and security

Order and vendor-application records are stored on the server. They are not sold or shared with payment, analytics, advertising, or delivery providers by this preview. The preview contains no analytics or advertising SDK. If the marketplace later adds payments, delivery, messaging, or other providers, this policy must be updated to name those services and explain the data shared with them.

Retention and deletion

The current preview does not automatically delete order requests or vendor applications. The operator must define and implement a retention schedule, backups policy, and a way for people to request access to or deletion of their information before real users are onboarded. Do not submit sensitive financial details; no payment is collected.

Children

This preview is intended for general audiences and is not designed specifically for children.
